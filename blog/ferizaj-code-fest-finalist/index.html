Finalist at Ferizaj Code Fest

By Dion Sherifi · June 28, 2025 · 5 min read
HackathonFerizaj Code FestBackendDION SHERIFI Bookings

On 28 June 2025, at Teatri ADRIANA in Ferizaj, Digital School Ferizaj held the second edition of Ferizaj Code Fest — the biggest coding competition in the city, where students present real, working tech projects in front of a live audience.

It wasn't just a competition. It was a full event: project showcases, prizes for finalists and winners, gifts for guests, and a serious push to inspire young people in Ferizaj to take technology seriously as a career.

The Project: DION SHERIFI Bookings

I entered with DION SHERIFI Bookings, a full booking platform I built to handle real reservations end-to-end — from picking a service and a time slot, to confirming and managing the booking in an admin panel. You can find the full project in my work section.

Top 5 in the Backend Category

Out of many projects across multiple categories, DION SHERIFI Bookings was voted Top 5 in the Backend category — which was treated as the highest, most technical category of the event. That meant a lot to me, because backend is where I had been putting in most of my hours.

What I Took From It

Demoing a project live in front of judges and an audience is a completely different skill from building it. You realize fast that a clean explanation matters as much as clean code. Since Ferizaj Code Fest, I've put real effort into being able to explain *why* I built something, not just *what* it does.
